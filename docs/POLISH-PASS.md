# Polish pass — usability, accessibility and documentation (2026-11-10)

Scope: fix rough edges found by exercising the running app in a real browser, and document the app with screenshots. No new features, components, providers or schema changes; IR v1 is untouched.

## Findings and fixes

| Finding (measured in Chromium)                                                                                                                          | Fix                                                                                                                                                                  |
| ------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Native drag of a Layers row was cancelled immediately (`dragstart` followed by `dragend`) because React state changed synchronously inside `dragstart`. | State updates are deferred one task (`setTimeout(0)`) and cancelled on `dragend`. Real-mouse drag now moves nodes.                                                   |
| Dropping on any non-target area of the tree silently moved the node to the root.                                                                        | Only before/inside/after targets accept drops; elsewhere nothing moves, no history entry, status says so.                                                            |
| axe-core: serious `color-contrast` (23–30 nodes, ratios down to 2.89:1).                                                                                | Muted/purple/red/green text tones darkened to WCAG AA (>= 4.5:1); tiny sizes raised to >= 11px. The intentionally disabled "AI (server)" label keeps a lighter tone. |
| axe-core: `landmark-unique`, `page-has-heading-one`, `scrollable-region-focusable`.                                                                     | Labelled landmarks, exactly one (visually hidden) `h1`, focusable code block.                                                                                        |
| Tabs had no state exposed; stale "Copied" message survived a tab change.                                                                                | `aria-pressed` on tab buttons; message cleared on change.                                                                                                            |
| On a 390 px screen, Generate / Export results landed off-screen (artboard at y=1109 of 844).                                                            | Canvas scrolls into view (respecting reduced motion) and a polite live region announces the update.                                                                  |
| Mobile heading rendered "Small prompt.New possibilities."                                                                                               | Fixed line-break handling.                                                                                                                                           |
| Internal "PHASE 03" text in the UI; no favicon or meta description; empty buttons/inputs had no accessible name; decorative glyphs read aloud.          | Badge reads "LOCAL WORKSPACE"; favicon + description added; fallback names; glyphs `aria-hidden`; optional inspector fields show "none (optional)".                  |
| `npm audit`: minimatch DoS advisory (GHSA-g3hv-75wg-m249) via ESLint tooling (dev only).                                                                | `overrides` pins minimatch 11.0.5; lint and tests unchanged; audit reports 0 vulnerabilities.                                                                        |

## Verification

Run on Node 24 in a clean install: `npm run format:check`, `npm run lint`, `npm run typecheck`, `npm test` (105 tests, 9 new), `npm run eval:offline`, `npm run build`, `npm audit`. Browser checks used Playwright with Chromium and axe-core 4.10.2: after the fixes axe-core reports no remaining violations on the main screen; no horizontal overflow at 1440/768/390 px for all four samples; edit, undo, Ctrl+Z, reload persistence and real-mouse drag/drop all work.

Not verified: live AI generation, touch-native dragging, Safari/Firefox, real screen readers, production security headers (CSP).
